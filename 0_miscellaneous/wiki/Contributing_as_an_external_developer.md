## Contributing your code as an external developer

OpenMarkov is structured as a set of [modules](OpenMarkov's_organization.md), if you wish, you can
develop a new module on this structure and contact us at **contributions@openmarkov.org** to discuss
including it in the official releases.

In some cases, we will allow external developers to modify OpenMarkov's existing modules.
In this case:

1. Create a branch of on the
   [OpenMarkov project](https://github.com/OpenMarkov/OpenMarkov/tree/development) for your
   purposes. This way, when you wish, the developers at the [CISIAD](http://www.cisiad.uned.es) will
   be able to examine the new code.
2. Once the [CISIAD](http://www.cisiad.uned.es) member(s) have approved the code and the contributor
   signs a distribution agreement license, the contribution will be merged with the official code.
