Welcome to the wiki of [**OpenMarkov**](http://www.openmarkov.org/), an open source tool for
building and evaluating probabilistic graphical models.

# For users

You can **download** OpenMarkov's executables from the
[users' page](http://www.openmarkov.org/users.html).

Other resources:

* [OpenMarkov's main page](http://www.openmarkov.org).
* [Tutorial](http://www.openmarkov.org/docs/tutorial/).
* [Learning Bayesian networks with OpenMarkov](http://www.openmarkov.org/learning/).
* [Contributing by reporting bugs and giving new ideas](Contributing_reporting_bugs_and_giving_new_ideas.md).

# For developers

If you wish to develop code in OpenMarkov, you should first
[install an IDE and set up an OpenMarkov project](Setting_up_an_OpenMarkov_project_in_an_IDE.md).

Once then, there are certain Wiki pages you'll find useful for developing in OpenMarkov:

* [OpenMarkov organization](OpenMarkov's_organization.md): explanation and graph of OpenMarkov's
  modules.
* [Development standards](Development_standards/index.md): good practices for OpenMarkov
  developers and how to add specific elements, such as new metrics and algorithms for learning and
  other extension points.
* [Contributing as an external developer](Contributing_as_an_external_developer.md): how to develop
  a new module for OpenMarkov.
* [Contributing by reporting bugs and giving new ideas](Contributing_reporting_bugs_and_giving_new_ideas.md):
  you can also contribute specifying the bugs/errors you found in the app or giving ideas such as
  new features or improvements. All of this is made through
  [issues](https://github.com/OpenMarkov/OpenMarkov/issues/new/choose), which come in multiple
  forms to specify the bug or idea.
* [Using OpenMarkov as a dependency](Using_openmarkov_as_a_dependency.md): how to add OpenMarkov as
  a dependency for your projects.
* [Java's Metaprogramming Overview and Tutorial](Java's_Metaprogramming/Java's_Metaprogramming_Overview_and_Tutorial.md):
  and overview to Java's Annotation Processing as a Metaprogramming system; It includes a tutorial
  on how to use it.

Other resources:

* [Javadoc](http://www.openmarkov.org/javadoc/).
* [Technical documents](https://bitbucket.org/cisiad/org.openmarkov.doc/src/master/).
* [Useful plugins for IntelliJ](IntelliJ/Plugins_of_interest.md).
