Input Action
Double-click on empty space Creates a new node and opens its properties.

Note: cancelling the properties will erase the node.
Right click Opens a contextual menu for the selected element.

Right-clicking on an empty spaces shows a contextual
menu for the network itself.
Hold Ctrl + Shift When at least one node is selected, it shows an arrow
with which you can select another node to create a link.

Pressing the "Alt" key will change the direction of the arrow.
